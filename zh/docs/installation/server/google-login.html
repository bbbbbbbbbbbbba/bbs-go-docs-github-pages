Google 登录配置 ​

本文档说明如何在 BBS-GO 中启用 Google 登录（含登录与账号绑定）。

1. 前置条件 ​

  • 站点可通过公网域名访问（生产环境）
  • 已完成 BBS-GO 安装并可进入管理后台
  • 有可用的 Google Cloud 项目

2. Google Cloud Console 创建 OAuth 凭据 ​

  1. 打开 Google Cloud Console：https://console.cloud.google.com
  2. 进入 APIs & Services -> Credentials
  3. 点击 Create Credentials -> OAuth client ID
  4. Application type 选择 Web application
  5. 填写授权来源与回调地址

2.1 Authorized JavaScript origins ​

请添加你的站点来源（示例）：

  • https://bbs.example.com
  • 开发环境可加：http://localhost:8082

2.2 Authorized redirect URIs ​

必须添加以下两个回调地址（按你的域名替换）：

  • https://bbs.example.com/user/signin/callback/google
  • https://bbs.example.com/user/signin/callback/google_bind

开发环境示例：

  • http://localhost:8082/user/signin/callback/google
  • http://localhost:8082/user/signin/callback/google_bind

创建完成后你会拿到：

  • Client ID
  • Client Secret

3. 在 BBS-GO 后台配置 ​

进入管理后台：系统设置 -> 登录配置 -> Google 登录

填写并保存：

  • 是否启用：开启
  • Client ID：Google 控制台生成的 Client ID
  • Client Secret：Google 控制台生成的 Client Secret

4. 关键配置说明（BaseURL） ​

BBS-GO 会用服务端配置中的 baseURL（示例文件里可能写作 BaseURL）来拼接 Google 回调地址。

请确保 bbs-go.yaml 中该值为你的完整站点地址，例如：

yaml
baseURL: https://bbs.example.com

如果仍是 /，Google 回调地址可能不是完整 URL，导致登录失败。

5. 验证配置是否生效 ​

  1. 打开登录页：/user/signin
  2. 确认出现 Google 登录按钮
  3. 点击后应跳转到 Google 授权页
  4. 授权后应回到站点并登录成功

账号绑定验证：

  1. 登录后进入用户资料账号绑定页
  2. 发起 Google 绑定
  3. 授权后返回并显示已绑定

6. 常见问题 ​

redirect_uri_mismatch ​

原因：Google Console 中配置的回调地址与实际回调地址不一致。

处理：

  • 核对 Authorized redirect URIs
  • 核对 bbs-go.yaml 的 baseURL
  • 同时检查是否误用了 http/https 或端口

提示 Google 登录未启用 ​

原因：后台未开启 Google 登录。

处理：

  • 后台 系统设置 -> 登录配置 开启 Google 登录
  • 确认 Client ID / Client Secret 已保存

本地可用，线上不可用 ​

通常是域名、协议、端口不一致导致。

处理：

  • 线上域名加入 Authorized JavaScript origins
  • 线上回调地址加入 Authorized redirect URIs
  • 保证 baseURL 与线上访问域名一致
