服务部署 ​

本文档对应当前版本的一体化部署方式：bbs-go 启动后同时提供站点、后台和 API。

1. 前置条件 ​

  • 数据库：
    • 生产环境建议 MySQL 8+
    • 本地试用可选 SQLite

2. 获取与准备 ​

推荐使用发布包：

  1. 从 Releases 下载对应平台压缩包
  2. 解压到目标目录
  3. 进入解压目录，确认存在 bbs-go、site/、admin/、res/、locales/

3. 启动服务 ​

在发布包目录运行：

bash
# Linux/macOS
./bbs-go

# Windows
bbs-go.exe

默认端口：8082。

4. 首次安装 ​

未安装状态下，访问：

text
http://<host>:8082/install

安装向导支持：

  • 语言选择：en-US / zh-CN
  • 数据库类型：MySQL / SQLite
  • 站点信息与管理员初始化

安装成功后会自动写入 bbs-go.yaml，并完成初始化迁移。

5. 访问地址 ​

  • 前台：http://<host>:8082/
  • 后台：http://<host>:8082/admin
  • API：http://<host>:8082/api/*

6. 生产建议 ​

  • 使用 MySQL 作为生产数据库
  • 通过反向代理（Nginx/Caddy）提供 HTTPS
  • 定期备份数据库和上传资源
  • 使用 systemd/supervisor/容器平台管理进程

7. 常见问题 ​

端口被占用 ​

修改 bbs-go.yaml 中 Port 或释放占用端口。

安装页无法进入 ​

确认服务已启动，并访问 /install；若已安装会自动跳转首页。

SQLite 说明 ​

SQLite 适合本地体验和小规模试用；生产环境建议 MySQL。
