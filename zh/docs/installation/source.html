源码编译 ​

只有在需要自定义构建、本地开发或参与项目贡献时，才建议从源码编译。普通安装请使用 发布包安装 或 Docker 部署。

环境要求 ​

  • Go 1.23+
  • 如果需要构建前端资源，需要 Node.js 和 pnpm
  • SQLite 或 MySQL 8+

安装 Go ​

从 Go 官网下载安装包：

https://go.dev/dl/

验证安装：

bash
go version

可选：配置 Go Proxy ​

如果依赖下载较慢，可以设置 Go 代理：

bash
go env -w GOPROXY=https://goproxy.cn,direct
go env -w GOSUMDB=sum.golang.org
go env -w GO111MODULE=on

检查结果：

bash
go env | grep GOPROXY

编译 ​

在源码仓库中执行：

bash
go mod download
go build -o bbs-go main.go

如果你使用的是完整项目仓库，请以仓库 README 中的构建脚本为准。

运行并安装 ​

启动编译后的程序：

bash
./bbs-go

打开：

text
http://localhost:8082/install

后续按安装向导完成初始化。
