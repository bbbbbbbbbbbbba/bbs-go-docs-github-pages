推荐首次体验流程 ​

多数用户建议先使用发布包：

  1. 下载最新发布包：https://github.com/mlogclub/bbs-go/releases/latest
  2. 解压对应平台的压缩包。
  3. 运行 bbs-go。
  4. 打开 http://localhost:8082/install。
  5. 按安装向导完成初始化。

安装后访问 ​

  • 前台：http://localhost:8082/
  • 管理后台：http://localhost:8082/dashboard

Docker 部署默认对外暴露 3000 端口：

  • Docker 前台：http://localhost:3000/
