BBS-GO 安装使用手册 ​

1. 系统要求 ​

  • 操作系统：Windows / macOS / Linux
  • 内存：建议 2GB+
  • 数据库：
    • 生产环境建议 MySQL 8+
    • 本地体验可用 SQLite

2. 下载发布包 ​

发布地址：https://github.com/mlogclub/bbs-go/releases/latest

平台文件名
Windowsbbs-go-windows-x86_64.zip
macOS Intelbbs-go-macos-amd64.zip
macOS Apple 芯片bbs-go-macos-arm64.zip
Linux 64 位bbs-go-linux-amd64.zip
Linux 32 位bbs-go-linux-386.zip

3. 启动程序 ​

解压后进入目录，运行：

bash
# Linux/macOS
./bbs-go

# Windows
bbs-go.exe

默认监听端口：8082。

4. 首次安装 ​

浏览器访问：

text
http://localhost:8082/install

安装向导步骤：

  1. 选择语言（en-US / zh-CN）
  2. 选择数据库（MySQL 或 SQLite）
  3. 填写站点信息
  4. 创建管理员账号
  5. 完成安装

安装完成后系统会自动初始化配置和数据。

5. 访问地址 ​

  • 前台：http://localhost:8082/
  • 后台：http://localhost:8082/admin

6. 常见问题 ​

端口被占用 ​

修改 bbs-go.yaml 中 Port，或停止占用进程。

数据库连接失败 ​

  • MySQL：检查地址、端口、用户名、密码、数据库名
  • SQLite：建议直接在安装向导中选择 SQLite，无需手工建库

生产环境建议 ​

  • 使用 MySQL
  • 使用 Nginx/Caddy 反代并开启 HTTPS
  • 定期备份数据库和上传文件
