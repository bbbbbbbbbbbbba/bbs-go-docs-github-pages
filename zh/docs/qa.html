常见问题 ​

TIP

本页整理面向论坛、问答空间、知识库和讨论场景评估 BBS-GO 时常见的问题。

BBS-GO 是什么？ ​

BBS-GO 是面向论坛、知识库与讨论场景的轻量级社区与问答平台。它开源、可自托管，并基于 Go 和 React 构建。

可以用 BBS-GO 搭建什么？ ​

你可以用它搭建公开论坛、产品社区、开发者支持社区、内部问答中心和知识分享社区。

BBS-GO 只是论坛吗？ ​

不是。论坛式讨论是核心场景之一，但 BBS-GO 也支持文章发布、问答式流程、标签、分类、搜索、通知、声誉激励和后台运营管理。

它和大型论坛系统有什么区别？ ​

BBS-GO 更强调实用的自托管部署、更低的运维负担，以及论坛 + 问答 + 知识发布的一体化体验。当你需要结构化讨论，但不想引入过重的企业级社区套件时，它会更合适。

可以私有化部署吗？ ​

可以。BBS-GO 面向自托管部署设计，支持 Docker、发行包和源码构建。

支持 Docker 吗？ ​

支持。请参考 Docker 部署 查看 compose 配置和单容器启动方式。

生产环境推荐使用什么数据库？ ​

生产环境推荐使用 MySQL。SQLite 适合本地试用和轻量评估。

是否支持多语言？ ​

支持。BBS-GO 目前支持 en-US 和 zh-CN，覆盖 Web 端体验和服务端消息。

在哪里可以试用？ ​

可以访问在线演示社区：https://bbs.bbs-go.com

在哪里反馈问题？ ​

请使用 GitHub Issues：https://github.com/mlogclub/bbs-go/issues
